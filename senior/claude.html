课程背景

时代之变

2023年人类步入AI原生时代，传统的编程与制造门槛正被全面降维。未来科技人才的核心壁垒，不再是死记硬背的底层语法和机械接线，而是定义真实需求、驾驭AI工具进行系统性决策的能力。高中阶段的学生正处于认知能力快速跃升的关键期，需要从"工具使用者"向"系统架构师"转变。

课程定位

本课程面向高水平中学生，以"十二天完成一台具备多智能体协同能力的物理AI移动机器人"为目标，融合北京师范大学与UNNC联合课题的学术视角与工业级工程标准，培养面向未来的AI协同工程项目开发人才。

课程背景溯源

本课程基于北京师范大学与宁波诺丁汉大学（UNNC）联合课程课题"AI具身智能产品工程营"（移动底盘方向），深度融合中国新工科教育改革方向、Fab Academy开源造物精神、PBL项目制学习方法、Design Thinking设计思维方法论，以及未来AI协同工程项目开发范式。课程旨在探索一条"中国新工科教育落地到K12阶段"的实践路径。

不同于传统教育中"先学理论再做项目"的线性路径，本课程采用"项目驱动、理论嵌入、AI赋能、多元协同"的环形学习模型。学生在真实工程问题中主动建构知识体系，AI作为全天候协作伙伴加速探索过程，教师作为项目教练引导深度思考与系统决策。

与初中组的本质区别

初中组："AI做所有事，学生只做决策"——体验创新导向，以AI生成全部代码和方案，学生专注于场景定义和选型决策。

高中组："AI做基础执行，学生做系统设计和深度决策"——系统工程导向，AI生成基础模块，学生负责系统架构、多智能体协同、白盒机理理解和学术型交付。

从"单点生成"到"多智能体协作流（Multi-Agent Workflow）"：教学范式从"输入提示词、生成单点结果"的线性黑盒体验，全面升级为"专家智能体编排体系"。

课程理念

核心教学理念

1. 从"黑盒生成"到"白盒机理"

独创"AI生成复杂要素 → 学生进行白盒机理剖析 → 仿真验证 → 物理实操重构"的逆向工程流。AI负责降维琐碎的底层语法编译和物理接线验证，释放70%的高价值时间，让学生专注于运动学反解、有限状态机构建及全局技术拓扑的设计与推导。

2. 从"被动接受"到"系统架构"

引导学生理解并操纵"基于状态机的多Agent异步协同"，通过飞书敏捷看板调度机械、硬件、代码、算法等多个专项AI Agent，实现从单纯的"工具操作员"向工业级"全栈系统架构师"的跨越。

3. 从"体验产品"到"学术交付"

最终交付包含数理公式推导、定量分析图表、Git Commit全留痕证据链的学术型开源作品集，精准对齐中国新工科战略及国家高素质科创人才鉴定标准。

4. 从"单兵作战"到"AI敏捷协作"

采用现代软件工程的"精锐双人组+数字化AI队友"敏捷开发范式，模拟真实工业研发的大兵团作战生态。在打通"端-网-云-虚拟仿真"的完整产品全周期闭环基础上，全面注入系统工程思维与学术严谨性。

5. 从"学以致用"到"用以至学"

传统教育追求"先学再用"，本课程强调"在真实问题中建构知识"。AI工具嵌入到机械结构理解、控制逻辑生成、代码调试、产品原型、用户体验设计和项目展示中。学生不是单纯"调用AI"，而是在机器人系统中理解AI与物理世界如何连接。

角色与生态重塑

学生角色

从"技术学习者"升级为"AI时代的系统架构师"和"多智能体流程定义者"。不仅要会问AI，更要学会把模糊想法描述为清晰问题，把单个问题扩展成完整流程，把AI的回答拆解成可执行的系统方案。

AI角色

从"辅助搜索工具"升级为"多智能体团队协作伙伴"。AI在课程中涵盖：机械设计Agent、嵌入式硬件Agent、嵌入式软件Agent、算法Agent、系统集成Agent等，形成完整的专家Agent协作体系。

教师角色

从"知识灌输者"升级为"项目教练与系统架构导师"。教师重点职责：帮助学生建立系统分析框架、指导多智能体编排、监督AI工具使用规范、推动团队协作与每日复盘、引导学术诚实性交付。

团队形态

从"传统分工小组"升级为"学生双人组 + 多AI Agent + 导师支持"的敏捷开发团队。人类负责目标、判断、审美、伦理和系统决策，AI负责加速生成与辅助执行，导师负责校准方向和保障学习质量。

六大教育框架深度融合

本课程并非单一方法的简单叠加，而是将以下六大教育框架有机融合进课程设计的每一个环节，形成独特的教学范式：

新工科教育

以"新工科"理念为指导，强调工程实践能力、系统思维能力与创新设计能力的培养。课程对接国家高素质科创人才鉴定标准，以"端-网-云-虚拟仿真"完整技术栈为载体，培养具备跨学科工程视野的复合型人才。学生在解决真实工程问题的过程中，建构起"需求分析-系统设计-原型开发-测试验证-迭代优化"的完整工程方法论。

跨学科教育（STEAM）

课程打破学科边界，有机融合：计算机科学（AI编程、前端开发）、电子工程（嵌入式系统、传感器技术、CAN总线通信）、机械工程（3D建模、数字制造、材料工艺）、数学（运动学建模、PID控制算法）、系统设计（产品定义、用户体验、系统集成）——让学生在真实项目体验中自然习得跨学科整合能力。

Fab Academy

继承MIT Fab Lab的"开源造物"基因，强调"用数字制造工具创造任何东西"的能力。课程引入Fab Academy的文档驱动学习模式：学生需建立个人数字作品集，每项工作均需记录设计过程、制造参数和测试结果。参考fabacademy.org的作业体系，要求学生撰写包含设计、制造、测试全流程的开源技术文档。

PBL项目制学习

以"十二天完成一台可运行的物理AI移动机器人"为核心驱动问题，学生在解决真实世界问题中主动建构知识。PBL六大贯穿要素：驱动性问题（真实场景的工程挑战）、持续探究（多轮迭代验证）、学生自主权（100%功能定义决策）、真实性（可运行的硬件实物）、反思与修改（每日复盘+测试报告）、公开展示（结营答辩+作品集发布）。

Design Thinking

以斯坦福d.school设计思维模型为框架，贯穿课程全流程：共情（用户研究、场景洞察）→定义（问题陈述、PRD撰写）→构思（方案头脑风暴、多方案对比）→原型（快速原型、3D打印、电路验证）→测试（功能测试、用户反馈、迭代优化）。强调以人为中心的创新方法，培养学生同理心与用户导向的设计意识。

未来AI协同工程项目开发

课程模拟真实工业级AI协同开发场景：（1）多Agent编排：机械设计Agent、嵌入式硬件Agent、算法Agent等多个AI角色协同工作；（2）AI原生开发流程：Vibe Coding自然语言编程、Prompt Engineering、AI辅助调试；（3）敏捷硬件开发：采用"精锐双人组+数字化AI队友"范式；（4）学术诚实性：Git Commit全留痕、AI使用记录透明化、验证结果可追溯。培养学生的"AI协作素养"与"工程伦理意识"。

融合机制：环形学习模型

六种教育框架在本课程中不是线性排列，而是形成"环形学习模型"：以Design Thinking的"共情-定义-构思-原型-测试"循环为主线，PBL的方法论贯穿其中提供项目骨架，Fab Academy的造物精神支撑物理实现，新工科教育提供系统性框架，跨学科教育打破知识边界，AI协同工程作为全流程加速器和能力放大器。六者相互赋能，形成一个完整的教育生态闭环。

课程总览

课程名称

AI具身智能产品工程营（高中组）—— 移动底盘方向

适用年级

高一、高二（具备一定英语、科学、基础编程或机器人操作经验）

营期安排

12天（含1天参访/专家讲座），每日6-8小时高效学习与实践

团队规模

双人精锐组 + 多AI Agent + 导师支持，每组配备统一硬件平台（SophiCar）

核心产出

物理AI移动机器人实物 + 开源GitHub仓库 + 学术型技术报告 + 数字孪生演示系统 + 路演视频

硬件平台

统一移动底盘（SophiCar/ESP32-S3核心板/CAN总线/多传感器套件）+ 数字制造设备（3D打印机/激光切割机）

课程整体架构

十二天一体的能力进阶路径：

系统认知层（第1-3天）→ 技术深化层（第4-9天）→ 系统交付层（第10-12天）

每一天都同步对应六大框架的相应阶段，实现从"系统认知"到"工程实践"再到"学术表达"的完整闭环。

- 编写 MQTT 断网重连保活与硬件看门狗复位固件。进行 HSV 视觉标定防环境光干扰。

高中组核心交付标准（与初中组的本质区别）

1. 学术诚实性交付：工程日志除标准格式外，包含运动学雅可比反解方程与卡尔曼滤波位姿定量分析图表，附带规范的 Git Commit 记录作为真实协作证据。

2. 具身智能云边协同：引入端云协同架构，通过小车摄像头回传视觉流并经由云端大语言模型（VLM）决策下发动作 JSON 动作原语，实现多 Agent 闭环控制，而非简单的图形化巡线。

3. V2X车路协同：部署智能路侧单元（RSU），利用高悬 YOLO 感知系统计算行车全局轨迹并通过 MQTT 广播调度，实现车路协同主动规避。

4. 数字孪生与 Web 3D 镜像：基于 Three.js 搭建 1:1 双向虚实联动孪生系统，结合 Cannon.js 物理引擎完成防碰撞刚体仿真与状态高频同步（延迟 < 50ms）。

5. 开源学术作品集：建立规范的 GitHub 开源仓库、LaTeX 排版的技术研究论文，可用于强基计划和综合评价的背景材料。
