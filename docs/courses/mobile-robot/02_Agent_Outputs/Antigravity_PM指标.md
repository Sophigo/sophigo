### 层级决策方法对照表

| 层级 | PM 动作 | 决策方法 | 评价标准 |
|------|--------|---------|---------|
| Layer 0 → Layer 1 | 发散 → 聚类 | AI 扩展 + 场景归类 | 数量 10 → 30，场景 3 个 |
| Layer 1 → Layer 2 | 30 → 5 | 三轴投票 | 影响面 / 创新度 / 我能碰 |
| Layer 2 → Layer 3 | 5 → 1 | 砍需求 | 问题清晰度 × 数据可得性 × AI 发挥空间 |

### 关联锚点（Checkpoint 问答用）

> **Q3: AI 怎么把不同问题关联起来的？**
> AI 可以做的事情：生成聚类标签、计算语义相似度、发现跨场景模式（如「等待」这个关键词同时出现在食堂、快递柜、电梯 3 个场景中），学生在 Embedding Demo 中可以肉眼看散点图聚类结果。

### 关联方法指南（给学生的操作步骤）

1. **打开 SDG 快速查表**，通读 8 个目标的「场景线索」列
2. **圈出**与你问题直接相关的 1-2 个 SDG
3. **填写关联模板**：直接关联必须有强逻辑，不能硬凑
4. **加分项**：查阅 SDG 子目标（如 SDG 4.4、11.7），找到最精准的子目标编号
5. **验证问题**：如果找不到任何一个 SDG 与你相关 → 你的问题可能太窄或有偏差，回到机会树重新审视
