## 一、课程总览

### 1.1 课程身份

| 维度 | 初中组 | 高中组 |
|------|--------|--------|
| **营地全称** | AI机器人产品体验营 | AI具身智能产品工程营 |
| **核心硬件方案** | 纯ESP32-CAM | MaixCAM-Pro + ESP32-S3 |
| **教学范式** | AI做所有事，学生只做决策 | AI做基础执行，学生做系统设计和深度决策 |
| **产出规格** | 可运行AI机器人 + 基础作品集 | 工业级开源作品集 + 学术型技术报告 |
| **学制** | 12天走读制 (8:30-18:00) | 12天走读制 (8:30-18:00) |
| **编组形态** | 双人精锐组 + AI Agent | 双人精锐组 + Multi-Agent编排 |
| **Bloom重心** | 记忆→理解→应用→分析→评价→创造（侧重应用和分析） | 侧重评价和创造，含数理公式推导 |
| **项目场景** | 博物馆导览 / 景区服务 / 校园巡检 | 工业巡检 / 园区配送 / 深空探测 |

### 1.2 课程主线

```text
发现问题 → 定义产品 → AI生成方案 → 参数化设计
    → 数字制造 → 嵌入式控制 → Agent接入 → 多模态交互
    → 数字孪生 → 集成优化 → 包装发布 → 路演答辩
```

## 三、每日节奏模板

### 3.1 标准日程

| 时段 | 安排 |
|------|------|
| 08:30-09:00 | **每日站会 (Daily Scrum)**：各组3分钟汇报昨日进度/今日计划/卡点 |
| 09:00-12:00 | **上午主课**：主题导入 + AI协作 + 核心任务 |
| 12:00-13:30 | **午餐 & 休息** |
| 13:30-14:00 | **午后唤醒**：AI工具小技巧分享 / 跨界案例赏析 |
| 14:00-17:10 | **下午实战**：动手制造 + 调试优化 + 成果交付 |
| 17:10-17:40 | **每日复盘 (Retro)**：今日成果展示 + Git Commit + 工程日志 |
| 17:40-18:00 | **次日预告 + 家长推送内容准备** |

### 3.2 教学铁律（贯穿12天）

**禁止行为 ❌**
- "今天我们来学习Python语法"
- "大家打开Fusion 360，跟着我画"
- "这个电路的原理是这样的，大家按照接线"

**标准行为 ✅**
- "告诉AI你的需求，它会给你3种方案"
- "AI已生成3个底盘模型，你从稳定性/重量/美观度选一个"
- "AI画好了电路图，按教程接线，有问题问AI"

| CDIO阶段 | 对应Days | 初中组特征 | 高中组特征 |
|----------|---------|-----------|-----------|
| **C (Conceive) 构思** | Day 1-2 | AI全量辅助头脑风暴 | 多Agent协同 + 专利检索 + 技术拓扑 |
| **D (Design) 设计** | Day 3-4 | AI生成3方案，学生选型 | 参数理解 + CMF/DFM规范 + 供应链 |
