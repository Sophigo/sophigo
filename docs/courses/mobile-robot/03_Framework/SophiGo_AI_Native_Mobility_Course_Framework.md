## 六、SophiGo课程定位

### AI Native Mobility Lab

AI具身智能移动机器人产品工程营

课程主线：

发现问题
→ 设计机器人
→ AI生成方案
→ 参数化设计
→ 3D打印制造
→ 嵌入式控制
→ Agent接入
→ 场景验证
→ 产品发布

### 推荐项目方向

初中组：
- 博物馆导览机器人
- 景区服务机器人
- 智能农业巡检机器人

高中组：
- 工业巡检机器人
- 园区配送机器人
- 月球探测机器人

### 月球探测机器人优势

结合：

- AI Agent
- 自动驾驶
- SLAM
- 机械设计
- 联合国SDGs
- 航天工程

同时与 SophiCar 移动平台形成统一品牌体系。
