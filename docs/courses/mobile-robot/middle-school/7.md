## 第七天：全栈 Vibe Coding

**上午**

- **零代码界面构建**：跳过繁琐的 UI 代码编写，学生通过纯自然语言与 AI 对话进行全栈 Vibe Coding（100% 学生决策）；指挥 AI 自动编译出美观的 HTML 网页或小程序交互控制界面，包含前进、后退、左转、右转和停止按钮（100% AI 执行）。

**下午**

- **跨网控制控制链搭建**：学生将编译好的界面部署上线，通过 Wi-Fi 协议将网页端与机器人主控板进行跨网桥接。

**工具**

- **界面编译**：VSCode 插件、HTML5 / CSS / JavaScript 零代码生成器。
- **通信协议**：本地 Wi-Fi 通信模块。

**产出**

- **数字资产**：跨平台前端控制网页 / 小程序全套源码包、AI 对话控制接口配置文档。
- **实物成果**：成功实现 HTML 无线控制的移动机器人交互终端。
