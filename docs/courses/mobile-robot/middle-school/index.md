# 2.3 初中组：AI机器人产品体验营

参考原先课程资料，将 12 天内容整理为课程表。点击主题或内容摘要中的详情链接查看每天安排。

| 天数 | 主题 | 内容摘要 |
|---:|---|---|
| 1 | [问题挖掘](./1.md) | 明确真实问题，完成用户-场景-痛点拆解、竞品分析和基础 PRD 草稿。[详情](./1.md) |
| 2 | [功能定义](./2.md) | 完成模块化认知、提示词训练、用户流程、硬件方案、敏捷看板和项目网页。[详情](./2.md) |
| 3 | [参数化结构设计与数字制造](./3.md) | 学习 CMF/DFM 与参数化建模，完成三维模型终审和数字化加工准备。[详情](./3.md) |
| 4 | [嵌入式基础](./4.md) | 建立 ESP32-S3、电路、引脚、Wokwi 仿真和自然语言控制开发基础。[详情](./4.md) |
| 5 | [基础软硬件调试（一）](./5.md) | 推进整机机械总装、多外设硬件装配和工业级工艺优化。[详情](./5.md) |
| 6 | [基础软硬件调试（二）](./6.md) | 完成深度控制逻辑重构、多总线通信调优、硬件测试与故障排查记录。[详情](./6.md) |
| 7 | [全栈 Vibe Coding](./7.md) | 用自然语言生成网页或小程序控制界面，并搭建跨网控制链。[详情](./7.md) |
| 8 | [交互](./8.md) | 合并语音控制、网页控制和避障算法，让机器人具备多模态交互能力。[详情](./8.md) |
| 9 | [多模态语音交互集成与轻量化结构优化（一）](./9.md) | 测试完整系统，记录 Bug，进行控制逻辑优化和功能迭代。[详情](./9.md) |
| 10 | [多模态语音交互集成与轻量化结构优化（二）](./10.md) | 完成轻量化结构优化、产品化工艺定型、全功能代码和终极原型机。[详情](./10.md) |
| 11 | [包装](./11.md) | 生成产品海报、演示视频脚本、剪辑结果和 Web 端分享内容。[详情](./11.md) |
| 12 | [发布](./12.md) | 举办产品发布会、技术路演、项目演示、企业参访和结营交付。[详情](./12.md) |
