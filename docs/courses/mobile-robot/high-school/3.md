## 3. 参数化结构设计

**知识点**

- **分享**
  - 机器人概况；
  - 设计规范导临：了解基础机械原理和术语，了解 CMF（颜色、材质、工艺）与 DFM（可制造性设计）基础规范；公差概念；
- **实践**
  - 建立对机器人空间机械结构的感性认知；指挥 AI 快速生成手办及结构概念示意；
  - 参数化建模决策：理顺建模工具冲突，通过 `sophicar.com` 进行移动机器人的参数化设计；
  - 三维模型终审：学生从结构稳定性、整机重量、美观度三个维度对 AI 方案进行横向对比与关键选型决策；
  - AI 辅助编写 Fusion 360 API 脚本，实现 3D 模型算法自动生成与装配；

**工具**

- **模型生成**：`sophicar.com`、Fusion 360 AI 脚本；
- **三维渲染**：腾讯混元、MakerLab 等 AI 三维生成工具；

**产出**

- **数字资产**：包含 `.f3d` 或 `.stl` 等标准格式的最终三维底盘结构模型文件；
- **工程文件**：数字化制造应用探索与加工参数生成文档；
