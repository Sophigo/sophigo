## 5. 嵌入式基础

**内容**

- **分享**
  - 了解开源硬件与开源协议分类（MIT, GPLv3, Apache 2.0），明确合规边界；
  - 了解 ESP32 系列，电路基础，引脚定义，专注于“懂逻辑、明机理”；
- **实操**
  - AI 定义需求生成代码、接线图，并在 Wokwi 仿真校验；
  - 接线后烧录程序进行 I/O、A/D 测试；
  - PWM 控制速度与角度；
  - 把前进、转向、停止和速度校准的实测偏差反馈给 AI，迭代参数和代码；

**工具**

- ESP32-S3 核心板，直流电机，舵机，LED，显示屏，电源；
- Wokwi 虚拟仿真平台 / Aily Blockly / VSCode；
- 万用表。

**产出**

- 环境搭建；
- 基础硬件连接和基础代码控制；
- 运动学推导页、Wokwi 仿真模型、AI 控制固件、参数迭代记录、基础运动测试报告；
