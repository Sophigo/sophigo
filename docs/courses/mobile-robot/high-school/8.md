## 第八天：具身智能控制落地：基于边缘视觉的端云协同抓取

**内容**

- 分享：端云协同的物理 Agent 闭环；
- **实操**
  - **云端大脑拆解任务（纯文本大模型规划）**：网页端（Web Speech API）将用户的模糊语音（如：“把红色的危险品清理一下”）转为结构化 JSON，发送给云端 Qwen LLM（纯语言模型）。指挥 AI 编写 System Prompt，让大模型只输出一张纯文本的任务清单卡片（如：`{"目标物体": "红色物体", "动作": "抓取"}`），并通过 MQTT 发回本地机器人；
  - **本地眼睛锁定目标（边缘视觉图像计算）**：本地 MaixCAM-Pro 收到云端指令卡片后，立刻激活本地 YOLO 视觉模型去画面中寻找特征。图像数据完全在边缘端消化。芯片本地实时计算出目标在画面中的左右偏差（ΔX, ΔY）与距离远近（目标框面积），把“视觉画面”在本地直接收敛为底盘运动的速度与转向角度；
  - **机械爪物理收网（底层反馈与传感器融合）**：底盘闭环运动，配合多传感器融合完成精准抓取：
    - 直行抗打滑（IMU + 编码器）：小车驶向目标时，融合 IMU 角速度与电机编码器数据。即便赛场光滑地面打滑，小车也能随时自己修正路线，笔直对准目标；
    - 近距离急刹（超声波 + 本地视觉）：当超声波测距小于机械爪工作距离，或本地 YOLO 测得物体足够近时，ESP32 底盘立即停机，一键启动物理收网指令：机械臂下落、机械爪闭环合拢；
  - **安全防线与量化测试（容错机制与科研作品集）**：设计安全底线，测试系统性能，生成能用于升学申请的硬核图表：
    - 断网大平分（Fail-Safe）：因为照片本就不传云端，若赛场 Wi-Fi 抖动断网，小车只需由 ESP32 触发刹车，并自动无缝切换为全本地“超声波 + 本地 YOLO”的基础避障安全模式；
    - 科研数据交付：学生手动测算并绘制《纯文本云端响应时延 vs 本地视觉计算帧率量化表》，作为其强基综评 / 海外名校申请作品集的硬核量化数据；

**工具**

- 硬件：MaixCAM-Pro，IMU，动力输出，麦克风；
- 软件：Qwen LLM / VLM，Hugging Face，Aily Blockly，Web Speech API，YOLO；

**产出**

- 闭环的机器人与底盘；
- 实现“语音 / 文本 - 云端 VLM - 本地 MaixCAM-Pro 视觉定位 - JSON - ESP32 底盘执行”的多 Agent 控制流；
- 一份包含《动态响应时延（Latency）量化分析图表》的开源科创作品集页面（HTML / Markdown 格式）；
