## 2. 功能定义

**知识点**

- 分享：AI 概况；
- 导入 AI Native 工程思维：自然语言不是聊天，而是定义目标、上下文、约束和验收标准；
- **提示词工程进阶**：学习提示词三要素（目标、要求、约束）以掌握高效向 AI 提需求的技巧；
- 站在架构师角度建立具身智能机器人的“端-网-云-虚拟仿真”全局技术拓扑图；
- **概念外观与生图迭代**
  - 学生自主描述产品外观（颜色、形状、大小、材质）并手绘草图；
  - 指挥 AI 连续进行 3 次以上的文生图交互迭代，生成 5 张不同风格的机器人概念效果图；
  - 指挥 AI 生成交互运动的视频；
- 正式上线团队与项目介绍网页；
  - 部署本地 VSCode 开发环境与 Git 版本控制系统；
  - 配置 GitHub 版本控制系统，规范“学术诚实性日志”的首次 Commit 规范；
  - 展示：PRD 终稿，机器人外观概念图，视频，提示词练习作业；
- 搭建飞书任务看板。

**工具**

- **AI 创作端**：大模型（DeepSeek / Qwen / Kimi / 等）、文生图工具、AI 生视频：Seedance 等；
- **工程开发**：VSCode、Gitee / GitHub，Mermaid 拓扑绘制；
- **协作管理**：飞书文档。

**产出**

- 最终版 PRD 文档；包含设计文件（提示词练习作业、机器人外观概念图、用户使用流程图）；
- 团队与项目介绍网页；
