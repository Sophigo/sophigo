## 第七天：全栈 Vibe Coding

**内容**

- **分享**
  - Vibe Coding 与全栈开发；
  - 通信协议；
  - 前端与后端；
- **实操**
  - 零代码界面构建：跳过繁琐的 UI 代码编写，学生通过纯自然语言与 AI 对话进行全栈 Vibe Coding（100% 学生决策）；指挥 AI 自动编译出美观的 HTML 网页或小程序交互控制界面，包含前进、后退、左转、右转和停止按钮（100% AI 执行），同时预留摄像头、Three.js 位置；
  - 学生在 AI 指导下部署并配置边缘控制通信链，通过 MQTT / WiFi 协议将前端网页控制端与机器人主控板进行长连接跨网桥接；

**工具**

- **界面编译**：VSCode 插件、HTML5 / CSS / JavaScript，MQTT；
- **通信协议**：本地 Wi-Fi 通信模块；

**产出**

- **数字资产**：跨平台前端控制网页 / 小程序全套源码包、AI 对话控制接口配置文档；
- **实物成果**：成功实现 HTML 跨网无线控制的移动机器人交互终端；
