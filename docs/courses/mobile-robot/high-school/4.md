## 4. 数字制造

**知识点**

- **分享**
  - 实验室安全培训；
  - 数字制造方式；
- **实践**
  - 引导学生开发 AI 智能体：
    - 进行工业级 BOM（物料清单）成本优化；
    - 结构文件生成切片建议、材料选择、加工风险和装配顺序；
    - 3D 打印或激光切割底盘、外壳和传感器支架，记录加工偏差并回传给 AI 做修正建议；
    - 使用 BOM Agent 生成替代料、成本优化和采购风险提示，学生做最终取舍；
  - 操作加工软件；
  - 操作数字制造设备，使用 FDM 3D 打印机、激光切割机等，加工需要的零件；

**工具**

- 加工软件：Bambu Studio，激光切割软件，Blue Print Studio；
- FDM 3D 打印机、LCD 3D 打印机，激光切割机，激光雕刻机等；
- AI 工具：DeepSeek / Qwen / Kimi / 等。

**产出**

- 基础物理零件；
- BOM 清单和成本核算报告；
- 数字化制造文档。
