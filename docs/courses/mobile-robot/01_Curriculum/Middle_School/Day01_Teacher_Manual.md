## 三、教学法执行细节（Claude 出品）

### 3.1 Bloom 认知分层映射

| Bloom 层级 | Day 01 对应环节 | 学生可观测行为指标 |
|-----------|----------------|-------------------|
| **记忆** | 回忆真实不便体验；复述「用户-场景-痛点」三要素 | 不借助外部资料，口头列举 ≥5 个亲身经历的不便场景 |
| **理解** | 解读 AI 扩展问题，辨别真实需求 vs 想象产物 | 用自己的语言说明 ≥3 个 AI 扩展问题的含义及现实关联度 |
| **应用** | 将模板套用到 Top 5；使用飞书看板分解问题 | 5 分钟内独立完成 1 个问题的模板填写，三要素完整 |
| **分析** | 多标准投票；区分表面不便与系统性问题 | 陈述投票依据（≥2 条理由），按「表面症状 vs 根因」分类 |
| **评价** | 砍需求（5→1）；判断竞品分析的可借鉴性 | 用 ≥3 条标准论证最终选题 |
| **创造** | 从零定义 10 个问题；脑暴产品命名/Slogan/外观 | 产出候选清单(≥10条) + 有论证的最终选题 + 命名/Slogan |

### 3.2 CDIO 构思阶段五步法

**步骤 1：无预设观察（15min）**
教师只给一句话：「现在拿出纸笔，回想过去一周你在学校、家里、小区里遇到的任何『哎，要是这能更好就好了』的时刻。写下来，至少 10 个。没有对错。」
→ 设计意图：消除示范 = 消除模仿，逼迫调用真实体验。

**步骤 2：AI 灵感放大（20min）**
学生将 10 个问题输入 AI，用自己的话要求扩展 20 个相关问题。教师不示范 prompt，只说意图。
→ DeepLearning.AI 锚点：此环节即「语义空间」的第一直觉——AI 在数学空间里寻找「邻近的不便」。

**步骤 3：三轴投票（25min）**
引入三维评价标准：

| 标准 | 初中生语言 | 最低票数要求 |
|------|-----------|-------------|
| 影响面 | 这个问题影响多少人？每天发生几次？ | ≥1 票 |
| 创新度 | 现在有没有人已经在解决它？你想的是新招吗？ | ≥1 票 |
| 我能碰 | 以你和搭档的能力/资源，能尝试去解决吗？ | ≥1 票 |

每位学生 5 票，三轴各至少 1 票。

**步骤 4：用户-场景-痛点模板（25min）**
每个 Top 5 问题强制填写：
```
【用户】谁是受影响最大的人？（必须具体到某一类人）
【场景】在什么时间/地点/情境下发生？（画面感）
【痛点】为什么这个不便让人难受？（情绪 + 后果）
```
AI 辅助：将模板输入 AI，生成该用户「一日生活画像」。教师纠正：「『所有人』不是用户。」

**步骤 5：极限收敛（30min）**
1. 每人独立排 Top 5→1 顺序及理由(2min)
2. 交换，找最大差异点辩论(每人 3min)
3. 无法一致时用 SDG 关联度作 tiebreaker

### 3.3 DeepLearning.AI 降维教学：15 分钟「AI 如何理解文字」

| 时间 | 环节 | 操作 |
|------|------|------|
| 第 1-3 分 | 具身活动「你离谁近？」 | 5 名学生站前面，全班物理移动到「爱好最接近的人」旁边。教师转折：「你做的就是把『人』变成『位置』然后判断距离——AI 对文字做完全一样的事。」 |
| 第 4-8 分 | Demo 文字→位置 | 投屏 Embedding 可视化页面，输入「操场/篮球/食堂/图书馆/考试」等词，展示 2D 散点聚类。教师：「AI 没去过操场，它只是发现『操场』和『篮球』总一起出现，于是在数学空间里把它们放得很近。」 |
| 第 9-12 分 | 学生实操 | 学生输入自己的不便问题，让 AI 找 5 个语义最近的问题。观察：「食堂排队太长」被关联到「图书馆占座」——表面不同，AI 发现了共同维度（资源分配不均）。 |
| 第 13-15 分 | 抽象收束 | 板书三句话：①所有文字对 AI 来说都是一个位置 ②意思越接近，位置越靠近 ③你的问题是输入，AI 看到的不是字，是位置 |

### 4.3 ESP32-CAM 开箱体验（20min）

> ⚠️ 目的不是跑通完整 demo，而是让学生在「做产品」前亲手摸到硬件。

最小步骤：
```bash
# 1. 安装 esptool
pip install esptool

# 2. 烧录固件（教师提前编译）
esptool.py --port /dev/cu.usbserial-* --baud 460800 write_flash 0x0 camera.bin

# 3. 配网：上电 → 手机连 ESP32-CAM-XXXX 热点 → 浏览器 192.168.4.1 → 输入教室 Wi-Fi

# 4. 验证：浏览器访问 DHCP IP → 看到实时视频流 = 成功
```
